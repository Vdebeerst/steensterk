# WA Desktop Connector 1.0.0

Initial production release.

## Verified functionality

- Downloading the Windows installer from Odoo
- Installing the Windows Connector
- Opening XLSX, DOCX and PDF documents
- Opening supported spreadsheets in Odoo Spreadsheet
- Saving documents multiple times
- Synchronizing saved changes back to Odoo
- Reopening documents with all saved changes present
- Opening documents from the kanban view
- Opening selected documents through Actions > Open on Desktop
