# WA Desktop Connector 1.0.0

WA Desktop Connector integrates Odoo Documents with Windows desktop applications.

## Included

- Five Odoo 19 modules
- Windows Connector source
- Tested Windows installer
- Installer download from Odoo Documents
- Kanban and Actions integration
- Automatic synchronization after saving

## Odoo installation

Add the directories from `odoo_addons` to the custom-addons repository, restart Odoo,
update the Apps list and install or upgrade `wa_documents_desktop_connector`.

The dependent WA modules are installed automatically.

## Windows installation

Users can download `WA Desktop Connector Setup.exe` directly from Odoo Documents.
